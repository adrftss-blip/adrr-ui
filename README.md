# ADRR UI

A dark-themed mobile UI with bottom navigation bar.

## Features
- Clean dark background (#000)
- 5 Navigation icons at the bottom
- Responsive design
- Font Awesome icons

## Navigation Items
1. **Home** - Home icon
2. **Categories** - Folder icon
3. **Login** - Login icon (with pink circle background)
4. **Models** - User astronaut icon
5. **Channels** - Video icon

## Files Structure
- `index.html` - Main HTML file
- `style.css` - Styling
- `icons/` - Individual icon component files
  - `home.js`
  - `categories.js`
  - `login.js`
  - `models.js`
  - `channels.js`
