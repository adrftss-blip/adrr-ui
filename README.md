# ADRR Trading Platform UI

A dark-themed mobile trading platform UI with bottom navigation bar.

## Features
- Clean dark background (#0a0a0a)
- Header with navigation menu
- Responsive grid layout for content
- 5 Navigation icons at the bottom
- Active state highlighting
- Notification badge support
- Responsive design
- Font Awesome icons

## Navigation Items
1. **الرصيد (Wallet)** - Wallet icon
2. **العقود الآجلة (Futures)** - Chart line icon
3. **التداول (Trading)** - Exchange icon (Active)
4. **الأسواق (Markets)** - Bar chart icon
5. **الصفحة الرئيسية (Home)** - Home icon with notification badge

## Files Structure
- `index.html` - Main HTML file with semantic structure
- `style.css` - Complete styling with responsive design
- `icons/` - Individual icon component files
  - `wallet.js` - Wallet component
  - `futures.js` - Futures component
  - `trading.js` - Trading component (active)
  - `markets.js` - Markets component
  - `home.js` - Home component with badge
